# Privacy Policy

**Effective Date:** January 1, 2024 (updated September 14, 2026)

## Introduction

GenericSuite ("we," "our," or "us") is an open-source software library designed to streamline frontend and backend workflows. This Privacy Policy explains how we handle information in relation to the GenericSuite software library and our documentation website.

This Privacy Policy also applies to **GS Doc**, our companion documentation viewer app for Android and iOS. GS Doc bundles this documentation locally on your device and does not download content at runtime; the data practices specific to GS Doc are described in the "GS Doc Mobile App" section below.

## 1. Information We Collect

### A. The GenericSuite Library

The GenericSuite software library itself does not collect, store, or transmit any personal data from its users or the end-users of applications built with it. It is a set of utilities and coding patterns that "live" within your own infrastructure.

### B. Documentation Website

When you visit our documentation website (e.g., genericsuite.carlosjramirez.com or genericsuite.readthedocs.io), we may collect anonymous usage data through standard web server logs or third-party analytics (like Google Analytics or ReadTheDocs analytics) to help us improve the documentation. This data may include:
- Browser type and version
- Operating system
- Referring website
- Pages visited and time spent

### C. Cookies

Our documentation website uses cookies set by Google Analytics to recognize repeat visits and measure how the documentation is used, as described above. Event-level analytics data is retained for 2 months and user-identifier data for 14 months, after which Google Analytics automatically deletes it (this window resets whenever you have new activity on the site). You can withdraw consent at any time by clearing the "Cookie consent" preference in your browser for this site, or by using your browser's cookie controls to block analytics cookies.

## 2. How We Use Information

Any information collected via the documentation website is used solely for:
- Analyzing trends and user engagement.
- Improving the content and structure of our documentation.
- Maintaining the security and performance of the site.

## 3. Third-Party Services

GenericSuite may integrate with third-party AI and cloud services if you choose to configure them, including but not limited to OpenAI, Anthropic, Google (Gemini / Vertex AI), AWS (including Bedrock), Groq, NVIDIA, xAI, and Hugging Face, as well as self-hosted options such as Ollama. We do not have access to the data you send to these services. You are responsible for reviewing the privacy policies of any third-party services you use in conjunction with GenericSuite.

## 4. Updates to This Policy
We may update this Privacy Policy from time to time. We will notify you of any changes by posting the new Privacy Policy on this page.

## 5. Contact Us
If you have any questions about this Privacy Policy, please contact us via our GitHub repository: [https://github.com/tomkat-cr/genericsuite-basecamp](https://github.com/tomkat-cr/genericsuite-basecamp).

## 6. GS Doc Mobile App

GS Doc bundles all documentation content locally on your device — it does not download documentation content at runtime, and does not use analytics, crash-reporting, or advertising services.

To render text, GS Doc uses the Google Fonts library, which retrieves the "Inter" font from Google's font servers over the internet the first time it is needed. This exposes your device's IP address to Google as part of that request. No other information is sent. See Google's privacy policy at https://policies.google.com/privacy for how Google handles this.

GS Doc requests no access to your camera, microphone, location, or contacts.
